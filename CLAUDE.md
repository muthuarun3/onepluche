# Consignes pour ce dépôt

- Langue : français (code, commentaires, messages de commit, PR).
- Vitrine : toute PR qui change ce que voit l'utilisateur (question, thème, état d'avancement,
  nom, adresse) met aussi à jour `vitrine/index.html` dans la même PR, avec la même direction
  artistique que l'appli. Si `static/style.css` change de couleurs, reporter les mêmes valeurs
  dans la vitrine (`tests/test_vitrine.py` le vérifie). Voir la section « Vitrine » du README.
